# VPNkerla

Нативный клиент VPNkerla для подключения по персональному ключу. Сайт: https://kerlavpn.ru.

В репозитории хранятся поддерживаемые изменения и закреплённые версии FlClash/ядра. Полные исходники восстанавливаются командой:

```sh
python native/materialize.py /absolute/new/vpnkerla-client
```

## Сборка

Изменения в pull request проверяются Android-сборкой. В Actions → VPNkerla native build можно также вручную выбрать Android, Windows, Linux или macOS. Поле API оставьте пустым для проверки действующего ключа без регистрации и оплаты.

При успешной сборке APK/пакет и SHA-256 появятся в артефактах запуска. Android — тестовая ARM64-сборка с отладочной подписью. Установка и реальная работа VPN на устройстве требуют проверки. iOS пока не реализован.

Тариф сервиса: 279 ₽ за 30 дней, до 3 устройств. Подключение платежей отложено. В репозитории нет персональных VPN-ключей, ключей подписи или секретов магазина.
