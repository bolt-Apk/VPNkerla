# VPNkerla

Нативное приложение VPNkerla для подключения по персональному ключу. Сайт: [kerlavpn.ru](https://kerlavpn.ru).

## Android-пилот

[Сборка № 5](https://github.com/bolt-Apk/VPNkerla/actions/runs/34558831066) успешно создала **VPNkerla-android-pilot.apk**. Все шесть клиентских тестов прошли. Проверены SHA-256, подпись, название VPNkerla и наличие VPN-ядра для ARM64. Результат: [native/BUILD-STATUS.json](native/BUILD-STATUS.json).

Это тестовая сборка для Android ARM64, API 24 и выше, с отладочной подписью. Установка и реальное VPN-подключение на физическом устройстве ещё не проверены. Регистрация и оплата в этой сборке не подключены; нужен действующий персональный ключ.

APK и контрольная сумма находятся в артефактах успешной сборки: **VPNkerla-android-pilot**. Распакуйте ZIP, установите APK, выберите «Добавить ключ», вставьте выданные ссылки и нажмите «Подключить VPN». Подробная инструкция: [native/GITHUB-BUILD-RU.md](native/GITHUB-BUILD-RU.md).

Windows, Linux и macOS предусмотрены в исходниках, но установщики ещё не собраны. iOS не реализован. Тариф сервиса — 279 ₽ за 30 дней, до 3 устройств; подключение платежей отложено.

## Исходники

Проверенные изменения объединены в основную ветку через [PR #1](https://github.com/bolt-Apk/VPNkerla/pull/1). Полный Flutter-проект восстанавливается из закреплённых версий, патча и дополнительных файлов:

```sh
python native/materialize.py /absolute/new/vpnkerla-client
```

Используйте текущую основную ветку с `native/` и `.github/workflows/native-pilot.yml`. Ранее загруженный ZIP — более старый снимок. Указанный в отчёте `sourceCommit` точно соответствует собранному APK; последующие изменения документации не меняют этот APK.
