# VPNkerla: состояние разработки, 11 сентября 2026

Подготовлены исходники нативного приложения и отдельного сервера аккаунтов.
Собраны нативные библиотеки Android arm64, но готового APK/EXE пока нет. Текущий сайт и работающий
VPN-пилот этими изменениями не заменялись.

| Часть | Состояние |
|---|---|
| Регистрация через код email | Код готов; реальная отправка писем не подключена |
| Тарифы и ЮKassa | Серверная логика и тесты готовы; продажи отключены |
| Три устройства | Проверено серверными тестами; аппаратная защита от копирования ключа отсутствует |
| Кнопка VPN | Нативный запуск с ожиданием применения профиля; на устройстве ещё не проверена |
| REALITY, XHTTP, Hysteria 2 | Профиль принят собранным mihomo; импорт трёх типов проверен тестами, реальное переключение ещё не проверено |
| Android arm64 | Нативные библиотеки собраны; APK остановлен на недоступных зависимостях |
| Windows, macOS, Linux | Исходные платформенные проекты; установщики не собраны |
| iPhone/iPad | Собственный VPN-модуль ещё не реализован |
| Telegram-вход | Ещё не реализован |
| 5000 пользователей одновременно | Нагрузочные испытания не проводились |

Пять серверных тестов прошли: одноразовые и истёкшие коды, повторные платежные
уведомления, неверная сумма/режим магазина, изоляция аккаунтов, отзыв устройств,
подтверждение применения ключа и ограничения HTTP. Платёжный и почтовый сервисы
в тестах заменены тестовыми адаптерами.

Flutter 3.47.1 и зависимости установлены, файл зависимостей закреплён.
Локализация сгенерирована штатным генератором. Анализ проекта завершился без
ошибок и предупреждений; осталась одна информационная рекомендация в неизменённом
тесте исходной основы. Шесть тестов нового клиента прошли: импорт REALITY, XHTTP,
Hysteria 2, проверка небезопасного ввода, резервная группа и форма добавления ключа.

Mihomo собран из закреплённого исходного кода (70f0570…), проверка конфигурации
трёх протоколов прошла. Это проверка синтаксиса конфигурации, а не соединения с
VPN-сервером. Добавлен режим подключения по уже выданному ключу без аккаунта и
оплаты. Он не создаёт бесплатный доступ: ключ должен действовать на VPN-сервере.

Готов сценарий сборки тестовых пакетов и ручной процесс GitHub Actions для
Android, Windows, Linux и macOS. Запуск в GitHub не выполнялся. Сборка Android
в текущей среде дошла до упаковки ресурсов приложения. Flutter-код и нативные
библиотеки `libclash.so` и `librust_api.so` собраны; у обеих библиотек проверен
формат ELF для ARM64. Исправлен поиск заголовков NDK для bindgen.

Последняя онлайн-попытка прошла обработку ресурсов APK, но среда заблокировала
доступ к `repo.maven.apache.org`. Проверка без сети 11 сентября остановилась на
`:app_links:compileDebugJavaWithJavac`: шесть версий модулей отсутствуют в кэше.
Список сохранён в `android-missing-dependencies.txt`. Готового APK нет.

В корне продуктового репозитория добавлен ручной процесс
`.github/workflows/native-pilot.yml`. Он восстанавливает исходники из закреплённых
версий и поддерживаемого патча, устанавливает средства сборки, запускает проверки
и сохраняет результат как артефакт. Для запуска не нужны ключи магазина или VPN.
Этот процесс ещё не выполнялся в GitHub. Нужен репозиторий VPNkerla с разрешённым
запуском Actions; имеющийся доступ не позволяет создать его автоматически.

## Что нужно для завершения запуска

1. Тариф утверждён: 279 ₽ за 1 месяц (30 дней), до 3 устройств.
   Единственный тариф сохранён в конфигурации; продажи пока отключены.
2. ЮKassa отложена по просьбе владельца. Позже настроить тестовый магазин и почтового отправителя. Секреты вводятся
   в закрытые настройки сервера, не в чат или исходники приложения.
3. Разместить API за исправным HTTPS, не занимая порты действующего VPN.
4. Собрать и проверить установщики на соответствующих ОС, настроить подписи.
   Для iOS нужны разработка Network Extension, Mac и аккаунт организации Apple.
5. Пройти оплату и подключение с реальных устройств; только после этого
   включить продажи и планировать масштабирование.

Смена протокола может помогать при отдельных видах фильтрации, но не гарантирует
обход всех ограничений. VPN не восстанавливает полностью отключённую передачу
данных. «Антизаглушка на всех операторах» не является подтверждённой функцией.
