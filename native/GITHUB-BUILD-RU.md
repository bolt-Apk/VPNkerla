# Сборка VPNkerla в GitHub

Проверенные исходники объединены в основную ветку через [PR #1](https://github.com/bolt-Apk/VPNkerla/pull/1).
[Android-сборка № 5](https://github.com/bolt-Apk/VPNkerla/actions/runs/34558831066)
успешно создала APK и прошла все шесть клиентских тестов. В скачанном файле
проверены контрольная сумма, подпись, название VPNkerla и VPN-библиотеки ARM64.
Точные данные итогового APK: [BUILD-STATUS.json](BUILD-STATUS.json).

1. Откройте [репозиторий проекта](https://github.com/bolt-Apk/VPNkerla) и основную ветку. Ранее загруженный ZIP — старый снимок; актуальные изменения находятся в текущем дереве исходников.
2. Исходники находятся в `native/`, сборка — в `.github/workflows/native-pilot.yml`. `upstream.json` закрепляет версии, `upstream.patch` хранит изменения основы, `overlay/` — дополнительные файлы. Workflow вызывает `materialize.py` и восстанавливает полный Flutter-проект перед сборкой. Локально выполните из корня репозитория `python native/materialize.py /absolute/new/vpnkerla-client`.
3. Для текущей сборки откройте **VPNkerla native build** в Actions. Workflow запускает Android для изменений в PR и также содержит ручной выбор платформы. Кнопка **Run workflow** в основной ветке позволяет выбрать Android вручную; поле API оставьте пустым.
4. После успешного запуска и проверки APK скачайте артефакт **VPNkerla-android-pilot**, распакуйте архив и откройте APK на телефоне ARM64. Это тестовая сборка с отладочной подписью. Если Android запросит разрешение установки, разрешите его для приложения, которым открыли APK.
5. Откройте VPNkerla. В блоке **«У меня уже есть ключ»** нажмите **«Добавить ключ»**. Вставьте действующую персональную ссылку из «Мои устройства» на [kerlavpn.ru](https://kerlavpn.ru) и нажмите **«Добавить ключ»** в диалоге. Несколько ссылок вставляйте сразу, каждую с новой строки. Содержимое текстового файла нужно скопировать в поле: отдельной кнопки выбора файла в этой форме нет. Принимаются до 20 ссылок VLESS REALITY, VLESS XHTTP/TLS или Hysteria 2; заголовки, комментарии и YAML/JSON не подходят. Повторное добавление заменяет сохранённый пилотный профиль.
6. Нажмите **«Подключить VPN»** и разрешите системное VPN-подключение. Android также может запросить уведомления. После статуса **«VPN включён. Проверьте открытие нужных сайтов.»** проверьте внешний IP, DNS, работу после блокировки экрана и смены сети. Эти проверки на физическом устройстве ещё не выполнены. Для остановки нажмите **«Отключить VPN»**.

Установщики Windows, macOS и Linux пока не собраны. Workflow предусматривает
эти платформы на соответствующих ОС. iOS требует отдельного VPN-модуля и
подписи Apple; в этой версии его нет.

В текущем Android-пилоте API, регистрация и оплата не подключены. Для входа через
email и покупки тарифов потребуется отдельный API и почтовый отправитель.
ЮKassa отложена; тариф сервиса остаётся 279 ₽ за 30 дней, до 3 устройств.

Нельзя подтвердить поддержку 5000 одновременных клиентов или работу при любом отключении интернета без соответствующих испытаний.
