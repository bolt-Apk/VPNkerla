# Сборка VPNkerla в GitHub

Этот комплект подготовлен для отдельного репозитория VPNkerla.
Сценарий ещё не запускался; APK и программы для ПК не выдаются за готовые.

1. Репозиторий проекта: https://github.com/bolt-Apk/VPNkerla.
2. Исходники находятся в `native/`, сборка — в `.github/workflows/native-pilot.yml`. Android-сборка запускается для изменений в pull request. Для этой структуры выбран процесс, который сам восстанавливает полный исходный код клиента; загружать папку `client/` вручную не требуется.
3. В GitHub откройте Actions → VPNkerla native build → Run workflow. Выберите Android, поле API оставьте пустым для проверки уже выданного ключа.
4. После успешной сборки скачайте артефакт VPNkerla-android-pilot. Это тестовая ARM64-сборка с отладочной подписью, не публикация в Google Play.
5. Установите приложение на Android, добавьте ключ из «Мои устройства» на kerlavpn.ru, нажмите «Подключить VPN» и разрешите системное VPN-подключение. Нужно проверить внешний IP, DNS, работу после блокировки экрана и смены сети. Эти проверки в текущем комплекте ещё не выполнены.

Windows, macOS и Linux выбираются в том же процессе и собираются на своих ОС.
iOS требует отдельного VPN-модуля и подписи Apple; в этой версии его нет.

Вход через email и покупка тарифов требуют развёртывания отдельного API и почтового отправителя. ЮKassa отложена; тариф остаётся 279 ₽ за 30 дней, до 3 устройств.

Нельзя подтвердить поддержку 5000 одновременных клиентов или работу при любом отключении интернета без соответствующих испытаний.
